## 상세 문서 작성 템플릿

```markdown

## 무엇을
한 문장 요약.

## 어디에
- `src/...`

## 왜
합쳐진 중복 지점을 나열.
- `src/components/A/A.tsx` 의 ...
- `src/components/B/B.tsx` 의 ...

## 사용법
\`\`\`tsx
// 코드 예시
\`\`\`

## 주의사항
- 확장 시 지켜야 할 것
```
